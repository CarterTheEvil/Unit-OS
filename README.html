⚙️ Unit-OS

A Mini Operating System Project
About This Project

This is a mini operating system I'm making. It's going to be 3 files total, and you may need to compile it yourself.

⚠️ Important: If there are only 1 or 2 files in the repository, this is still a work in progress. Do not compile until all 3 files have been released!

📢 Disclaimer This is not meant to be taken as a real operating system in production. This is purely for fun and educational purposes. Don't use it for anything critical!
📦 Installation Requirements

You need to install some packages on WSL/Linux for this to work:

$ sudo apt install gcc nasm grub-pc-bin grub-common xorriso qemu-system-x86
GCC NASM GRUB QEMU xorriso
🔨 Build Instructions

Once dependencies are installed, follow these steps:

  1. Clean any previous builds
    2. $ make clean
  2. Compile the OS
    3. $ make
  3. Run the compiled OS
    4. $ make run
