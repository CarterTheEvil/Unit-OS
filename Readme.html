Welcome to Unit-OS

This is a mini operating system I'm building as a hobby project. It boots via GRUB, runs under QEMU, and is written primarily in C and x86 Assembly.

The current version includes a bootable kernel with a minimal command interpreter, basic rendering, and PS/2 keyboard input support.

Compilation & Requirements

This project targets Linux or WSL (Windows Subsystem for Linux). You will need the following packages installed:

$ sudo apt install gcc nasm grub-pc-bin grub-common xorriso qemu-system-x86

Once dependencies are installed, build and run from the repository root:

$ make clean
 Step 1: Remove any previous build artifacts
$ make
 Step 2: Assemble & link the OS image
$ make run
 Step 3: Launch in QEMU

F.A.Q.

Q: Why does it look like a text mode OS?

A: It's Pre-Alpha v0.0.1. Text mode rendering is the foundation—we're not doing fancy graphics yet!

Q: Can I run this on real hardware?

A: Technically yes (GRUB + any x86 machine), but please don't. Use QEMU unless you have spare hardware.

Q: Does the keyboard work?

A: Yes! But it's PS/2 only. Modern USB keyboards won't be recognized without an adapter or PS/2 motherboard ports. Again, QEMU solves this.

Q: What's the roadmap?

A: More interrupts, a proper keyboard buffer, basic file I/O, and eventually a tiny shell. No promises on dates — this is a fun project, not a deadline.
